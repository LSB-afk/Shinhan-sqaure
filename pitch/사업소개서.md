# 사업소개서 초안 (15매 이내 → PDF)

> 근거·수치는 [docs/idea.md](../docs/idea.md). 우대 분야(AI금융·ESG)는 13장에서 확장으로 제시.

1. 표지 — (가칭) DropZero: 건설현장 낙하물 사고 AI 예방·경보 플랫폼
2. 문제 — 2025 사고사망 605명 중 건설업 286명, "물체에 맞음" 사망 유형 2위(72명). 그런데 낙하물에 특화된 솔루션이 없음
3. 왜 어려운가 — 낙하 시간 표(30m = 2.47초), 20px 소형 객체, 실제 데이터 부재
4. 해결책 — 3단 방어 `[도면: 03-process.png]`: 예방(노출 차단) / 대응(실시간 경보) / 학습(아차사고 데이터)
5. 1단 예방 `[도면: 01-site-layout.png]` — 인양물 동적 위험구역, 상하 동시작업 감지, 드론 정기순찰 리포트
6. 2단 대응 — 엣지 감지 → 물리 궤적 판별 → 착지점 예측 → 경광등·웨어러블·다국어 경보
7. 3단 관제·데이터 — 대시보드, 위험 히트맵, 법정 증빙 자동화
8. 기술 차별점 `[도면: 02-architecture.png]` — 물리 일관성 필터(오경보 억제), 지연 예산 0.2~0.35초, 엣지 단독 동작
9. 합성 데이터 — 3D 시뮬 + 실영상 합성 + 실측 평가세트, 시나리오 카탈로그
10. 데모 / PoC 결과 — 더미 낙하 → 감지 → 경광등 점등 영상
11. 시장·고객 — 중견 건설사 1차, 대형사 API, 소규모 현장은 지원사업
12. 비즈니스 모델 — 현장당 월 구독 + 렌탈, 산안비 100% 인정, 지원사업 최대 80%
13. 경쟁 구도 + AI금융·ESG 확장 — 위험 점수 → 보험 요율·PF 리스크 모니터링
14. 로드맵 + 리스크 대응 — 공모전 → 파일럿 → 제품화 → 금융 연계
15. 팀 — 역할과 역량, 연락처
